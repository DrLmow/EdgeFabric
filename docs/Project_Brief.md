# EdgeFabric 边缘互联

本工程主要集中于边缘设备的互联，边缘设备可以是带有少量传感器的STM32设备，亦或是带有蓝牙WIFI的ESP32模块，或者是嵌入式Linux设备，甚至是手机，电脑，服务器。让这些设备都能够将采集到的信息互相交换，例如自适应网络算法，或者是在某处使用从网络中得到的消息做出一些行为。此互联网络目标是实现一个自组网的通用解决方案。

EdgeFabric，以下简称edf

## 组成部分

1. 边缘设备
   在边缘设备上，edf需提供合适的API（同步，异步等）来满足不同应用的数据采集方式，同时需要提供合适的网络传输API，设备可以通过API来加入已经建立的网络，使得网络可以发现自己，并且向网络传输信息，或者从网络中获取信息。
2. 互联
   互联由多个路由节点组成，路由节点本身可以是边缘设备，也可以只是单纯的路由器。互联主要负责通过网络地edf址定位设备，决定网络中数据流的路由算法，同时负责发现并纠正在传输中出现的错误。
3. 网关
   edf网关是在边缘设备之外的设备，它在网络中的定位不是采集数据——尽管他可以这样做，它负责将网络中的数据流收集，整理，并向服务器上报。同时，它也可以作为网络中的保序点——即它可以实现网络中一些必须按照顺序完成的操作，同时，它可以负责广播信息，发现新设备，定时监测节点状态，定时重启，监测流量状态等
4. 服务器
   在edf语境中，服务器主要指具有大型CPU阵列，内存容量大，具有较高算力的计算机或计算机集群。服务器可以从一个或更多的网关中获取信息——网关和服务器可以是同一台设备，也可以不是同一台设备。服务器可以从网关中获取网络信息，或者通过网关和网络进行交互。服务器端edf会提供合适的API来满足不同的数据处理需求，数据可以被服务器任意使用，包括但不限于使用AI进行分析，网页展示，可视化监测，或者通过其他算法进一步处理。
